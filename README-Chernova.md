# Разработка автоматизированного приложения для управления библиотекой
Данный проект представляет собой автоматизированное приложение для управления библиотекой, предназначенное для упрощения процессов учета книг, читателей и выдачи литературы. Приложение позволяет библиотекарям быстро получать доступ к необходимой информации, автоматизирует рутинные задачи, такие как формирование отчетов, уведомлений о просроченных книгах и управление аккаунтами читателей.

## Начало работы
Эти инструкции помогут вам запустить проект на вашем локальном компьютере для разработки и тестирования.

### Необходимые условия
Для установки и запуска проекта вам потребуется следующее программное обеспечение:
- Node.js (версия 16.x или выше)
- PostgreSQL (версия 12.x или выше) 
- Git (для клонирования репозитория)
Установите Node.js и выбранную СУБД, следуя официальным инструкциям:
- [Установка Node.js](https://nodejs.org/)
- [Установка PostgreSQL](https://www.postgresql.org/download/)

### Установка
1. Клонируйте репозиторий на ваш локальный компьютер:

      git clone https://github.com/yourusername/gibdd-database-app.git

2. Перейдите в директорию проекта:

      cd library-management-app

3. Установите необходимые зависимости:

      npm install

4. Создайте файл .env в корневой директории проекта и настройте переменные окружения для подключения к базе данных.  Замените значения placeholder на ваши:

      DB_HOST=localhost
      DB_PORT=5432  
      DB_USER=yourusername
      DB_PASSWORD=yourpassword
      DB_NAME=library_db
      DB_DIALECT=postgres 

5. Запустите миграции для создания структуры базы данных:

      npm run migrate

6. Запустите приложение:

      npm start

7. После успешного запуска приложение будет доступно по адресу `http://localhost:3000`.
